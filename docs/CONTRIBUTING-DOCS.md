# Contributing to Docs

## Principles
- Keep docs accurate and concise.
- Update docs in the same MR as code changes.
- Use examples for commands and payloads.

## Naming
Use `Title-Case-With-Hyphens.md`.

## Required Updates
Update contracts when API shapes change:
- `docs/Auth-API-Contracts.md`
- `docs/Admin-API-Contracts.md`

Update integration docs when frontend auth flow changes:
- `docs/Frontend-Auth-Integration.md`

Update operations docs when deployment steps change:
- `docs/Deployment-Checklist.md`
- `docs/Go-Live-Runbook.md`

## Quality Checklist
- [ ] consistent with current code behavior
- [ ] linked from `docs/README.md`
- [ ] changelog updated when needed
